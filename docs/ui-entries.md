# 功能入口清单

同一对象、同一操作优先保留一个可见入口。增加新入口前检查既有侧栏、页签、页头按钮和行菜单。空态用文字说明位置，不再复制按钮。不同操作对象、输出结果及互斥状态不强行合并；保存快捷键和错误恢复继续可用。

| 功能 | 保留入口 | 本次删除的重复入口 |
| --- | --- | --- |
| 创建想法 | AI 工作台 → 想法地球输入框 | 顶部新建想法、记录空态新建、项目记录新建 |
| 查看全部记录 | AI 工作台 → 全部记录页签 | 地球底部查看全部记录 |
| 编辑记录 | 点击地球节点或列表中的具体记录 | 列表右键打开、双击聚焦 |
| 记录导出、删除 | 编辑器更多菜单 | 记录右键菜单 |
| 记录永久删除 | 回收站打开记录 → 编辑器更多菜单 → 永久删除 | 正常列表不提供此操作，确认后删除本地文件 |
| 新建项目 | 项目页头新建项目 | 项目空态新建按钮 |
| 编辑项目、备注 | 项目详情页头编辑 | 列表双击、右键编辑、空备注添加按钮 |
| 删除项目 | 项目详情页头删除项目 | 右键删除及只含一个动作的更多菜单 |
| 项目知识记录 | 项目详情知识记录页签 | 概览的知识与复盘卡片、项目记录列表跳转 |
| 部署 | 侧栏部署 | 项目概览部署卡片 |
| Git 扫描配置 | 设置 → Git 活动 | 项目活动源中的管理活动源跳转 |
| 扩展查看文档、启停、打开目录 | 扩展表格每行操作菜单 | 双击、右键菜单、选中后的底部操作栏 |
| 服务器管理 | 部署页头服务器管理 | 部署设置抽屉中的服务器管理按钮 |
| 更新日志 | 侧栏底部版本号 | 设置 → 应用信息中的查看更新日志 |
| Harness 更新 | Harness 页头更新按钮 | 服务设置中的更新按钮 |
| 填报账号配置 | 设置 → 一键填报 | 未配置提示中的去设置按钮 |

保留的上下文操作：

- 项目「打开终端」创建或聚焦该项目窗格；侧栏「终端工作台」只是进入工作台。项目「外部 PowerShell」另开独立系统终端。
- 项目根目录、关联仓库目录、扩展平台目录和单个技能/插件目录是不同对象，分别保留打开操作。
- 全局设置页签配置 AI/账号/界面；Harness 服务设置只配置 Harness 端口和自动启动，部署设置只编辑当前项目部署方案。
- 地球节点和记录列表显示同一记录的不同视图，点击具体记录属于内容操作；不会再添加重复的新建按钮或全局列表跳转。
- 错误重试、草稿另存、回收站恢复和运行中的取消操作有独立状态和作用，继续保留。

这次排查覆盖应用外壳、AI 工作台、项目、终端、Harness、一键填报、部署、扩展管理和设置。不修改 Harness 内嵌的第三方网页，也不删除本地记录、配置或业务能力。
