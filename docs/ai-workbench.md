# AI 工作台

## 日常使用

1. **先记录**：AI 工作台默认显示可拖动、缩放的 3D「想法地球」。输入一句话并按 Enter，想法会保存到本地知识库并立即成为地球上的光点；点击光点可打开详情。复杂内容用「新建想法」，支持 Markdown 编辑与预览。
2. **关联项目**：在记录中选择项目，或从「项目 → 知识记录」新建。项目备注继续承载项目简介，记录用于持续积累。
3. **查找与修改**：「全部记录」提供搜索、项目筛选和排序，搜索同时查找标题、正文、标签和项目名称。点击记录即可编辑标题、正文、标签或关联项目。
4. **精简范围**：当前仅保留「想法地球、全部记录、回收站」三个入口，移除 AI 分析、批量整理、多层知识分类、类型状态选择和模板。已有记录的类型、状态及来源元信息继续保存，不会删除或转写历史内容。

「设置 → AI 服务」支持保存多个配置，每份配置包含名称、接口地址、模型、温度和独立密钥。点击「新增配置」后填写并保存；修改当前配置后点击「保存配置」。选择其他配置时会先保存当前编辑，再启用选中配置，重启后保持选择。测试连接和获取模型使用当前配置的密钥；密钥留空保持原值，清除只影响当前配置。旧版本的单配置自动保留为「默认配置」。
「设置 → AI 服务」的配置管理继续供部署等其他模块使用；工作台保存想法不调用 AI。

可用快捷操作：Enter 快速记录；地球中拖动或用方向键旋转、滚轮缩放、Home 重置视角；Ctrl/Cmd+S 立即保存、Ctrl/Cmd+K 搜索、右键记录操作、双击聚焦编辑、拖入 Markdown 导入。删除只移入回收站，可恢复。

## 文件与可靠性

- 正式记录存于应用用户数据目录的 `knowledge/<UUID>.md`。工作台右上角更多菜单可以打开目录。
- 每份文件由 YAML 元信息与 Markdown 正文组成，元信息保存类型、状态、项目、来源、时间与修订号；一个记录对应一个稳定 ID。
- 输入后约 600ms 自动保存；Ctrl/Cmd+S 可立即保存。未保存编辑同时保存在本机 Webview 草稿缓存中，应用重启后恢复并尝试写回。旧 AI 分析缓存保留在本机，不主动删除。
- 保存采用临时文件、原子替换、版本与文件摘要校验。其他进程或编辑器改过文件后，旧草稿不会直接覆盖，界面会提示；可将本地草稿另存为新记录后刷新核对。
- 保存失败会保留当前草稿；请重试，或另存副本。读取损坏文件会报告文件名并保留原文件。
- 项目删除不会级联删除记录，历史项目名称仍可查看和筛选。
- 导入/导出支持 Markdown；导入总是创建新 ID，不覆盖已有记录。直接放入知识目录的文件需符合应用元信息格式，普通 Markdown 请从菜单或拖放导入。
- 如需 Git 管理，可自行管理知识目录的 Markdown 文件。本版本不自动创建仓库、提交或联网同步，也不定时发送知识给 AI。

## 导航调整

原「工作台」改为 AI 工作台；独立 AI 助手和活动报告页面已移除。旧报告历史文件保留。一键填报与其 Git 采集、部署中的 AI 辅助、Harness、终端继续独立使用。

## 开发验证

```text
node scripts/knowledge-selftest.cjs
node scripts/knowledge-state-selftest.cjs
node scripts/knowledge-rpc-selftest.cjs
node scripts/desktop-ui-e2e.cjs
npm run build:renderer
```

浏览器验收使用隔离 IPC 和模拟 AI，不调用真实服务；真实模型输出质量需在配置个人服务后验证。
