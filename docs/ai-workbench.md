# 知识库

## 日常使用

1. **先记录**。知识库默认显示可拖动、缩放的 3D「想法地球」。输入一句话并按 Enter，想法就会保存到本机。地球也会展示已保存的行动建议，以及带「基础模块」标签的方法记录。点击任一节点可编辑记录，也可查看已有的项目和记录来源。
2. **关联项目**：在记录中选择项目，或从工作台「记录与复盘」及项目概览「项目记录与复盘」进入，点击「记录项目想法」后新想法自动关联该项目。项目备注继续承载项目简介，记录用于持续积累。
3. **查找与修改**：「全部记录」提供搜索、项目筛选和排序，搜索同时查找标题、正文、标签和项目名称。点击记录即可编辑标题、正文、标签或关联项目。
4. **提炼模块和寻找方向**。打开「模块与灵感」，选择要对比的项目，以及与问题有关的想法、问题或已有方法。比如两个项目都做了审批记录，而你记下了“希望按处理人复盘”，可以把这两个项目和这条想法一起交给 AI。

### 从想法到行动

点击「生成建议」时，应用使用「设置 → AI 服务」中当前启用的模型。输入包括所选项目的名称、说明、备注和标签，每个项目最多 8 条近期 Git 提交标题，以及你选中的知识记录。没有 Git 仓库的项目也可用说明、备注及记录参与分析。资料不足时，先补充项目中已经实现的具体功能、遇到的问题或想达到的结果，再生成一次。

共性模块会引用至少两个项目，说明可以共用的能力及如何验证。行动建议结合你的材料给出下一步和验证方式。点击建议卡片的「保存到知识库」，共性模块会作为已整理的方法保存，行动方向会作为想法草稿保存。在「全部记录」按任一来源项目筛选，都能找到这条跨项目记录。打开记录可以查看项目依据，点击来源记录回到原文。单纯记录想法、打开页面或编辑条目都不会调用模型。

「设置 → AI 服务」支持保存多个配置，每份配置包含名称、接口地址、模型、温度和独立密钥。点击「新增配置」后填写并保存；修改当前配置后点击「保存配置」。选择其他配置时会先保存当前编辑，再启用选中配置，重启后保持选择。测试连接和获取模型使用当前配置的密钥；密钥留空保持原值，清除只影响当前配置。旧版本的单配置自动保留为「默认配置」。

可用快捷操作：Enter 快速记录；地球中拖动或用方向键旋转、滚轮缩放、Home 重置视角；Ctrl/Cmd+S 立即保存、Ctrl/Cmd+K 搜索、拖入 Markdown 导入。「全部记录」页签是列表入口，点击记录打开编辑器；导出和删除统一放在编辑器更多菜单中。删除只移入回收站，可恢复。

需要彻底删除时，在「回收站」打开记录，选择编辑器更多菜单中的「永久删除」，核对标题后确认。本地记录文件和当前草稿会移除，删除后无法恢复；正常记录不提供此操作。若记录已被恢复、版本更新或在外部编辑过，操作会拒绝，请刷新后核对。

## 文件与可靠性

- 正式记录存于应用用户数据目录的 `knowledge/<UUID>.md`。工作台右上角更多菜单可以打开目录。
- 每份文件由 YAML 元信息与 Markdown 正文组成，元信息保存类型、状态、项目、来源、时间与修订号；一个记录对应一个稳定 ID。
- 输入后约 600ms 自动保存；Ctrl/Cmd+S 可立即保存。未保存编辑同时保存在本机 Webview 草稿缓存中，应用重启后恢复并尝试写回。旧 AI 分析缓存保留在本机，不主动删除。
- 保存采用临时文件、原子替换、版本与文件摘要校验。其他进程或编辑器改过文件后，旧草稿不会直接覆盖，界面会提示；可将本地草稿另存为新记录后刷新核对。
- 保存失败会保留当前草稿；请重试，或另存副本。读取损坏文件会报告文件名并保留原文件。
- 项目删除不会级联删除记录，历史项目名称仍可查看和筛选。
- 导入/导出支持 Markdown；导入总是创建新 ID，不覆盖已有记录。直接放入知识目录的文件需符合应用元信息格式，普通 Markdown 请从菜单或拖放导入。
- 如需 Git 管理，可自行管理知识目录的 Markdown 文件。本版本不自动创建仓库、提交或联网同步，也不定时发送知识给 AI。

## 导航调整

默认首页为项目工作台，原想法工作台更名为知识库；独立 AI 助手和活动报告页面已移除。旧报告历史文件保留。一键填报与其 Git 采集、部署中的 AI 辅助、Harness、终端继续独立使用。

## 开发验证

```text
node scripts/knowledge-selftest.cjs
node scripts/knowledge-state-selftest.cjs
node scripts/knowledge-rpc-selftest.cjs
node scripts/knowledge-insights-selftest.mjs
node scripts/desktop-ui-e2e.cjs --knowledge-only
node scripts/desktop-ui-e2e.cjs --globe-only
node scripts/desktop-ui-e2e.cjs
npm run build:renderer
```

浏览器验收使用隔离 IPC 和模拟 AI，不调用真实服务；真实模型输出质量需在配置个人服务后验证。
