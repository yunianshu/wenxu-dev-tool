## 设计语言

**方向**：保留左侧导航栏（浅色），重做内容区——整页是一张白色版面，分区之间只用 1px 细线
分隔，取消「每块内容一个圆角卡片」的堆叠；层级由标题字号 + 分隔线 + 留白建立。

**令牌**

| 用途 | 值 |
|---|---|
| 主强调色 | `#0E7A6D`（唯一），深 `#0B6257`，浅底 `#E7F2F0` |
| 页面底 / 主面 | `#F5F6F7` / `#FFFFFF` |
| 分区线 | `#E8EBEE`（浅 `#F1F3F5`） |
| 正文 / 辅助 / 元信息 | `#22282E` / `#5F6A73` / `#8A9096` |
| 语义色 | 成功 `#0F7B4F`、警告 `#B45309`、危险 `#C0342B` |
| 圆角 | 6 / 8 / 10 |
| 控件高 | 默认 36px，主操作与主要点击区 40px 起 |

**排版**：页面标题 26/600，分区标题 16/600，正文 14，辅助说明 13，元信息 12。
数字使用正文字体的等宽数位（tabular-nums）并左对齐——不用等宽字体渲染大数字，
避免斜杠零在大字号下变成难辨的 θ 形。

**内容区规则**

- 分区带：白底 + 顶部 1px 细线，无圆角、无投影；末带补底部细线收口
- 分区标题行：左右内边距 32px，底部细线，右侧放一个文字操作（如「查看全部」）
- 列表行：高 50px，序号列 + 名称（14/600）+ 状态右对齐 + 进入箭头，行间细线
- 状态：圆点 + 文字（进行中/已暂停/未归档），语义色只出现在圆点上
- 说明性文案不进界面：页面标题下不写说明句、面板不加副标题、设置项下不写提示段、
  空状态只保留状态标签（如「暂无记录」）与下一步操作

**与实现的一处有意偏差**：`清空`（对话 / 发布历史）在代码里保留危险色（可逆性差、
高频误触代价高），设计稿用中性文字按钮。
