# AI 工作台界面交付

当前实现：`src/views/AIWorkbenchView.vue` 与 `src/components/knowledge/`。沿用桌面 v2 浅色 / 黑色语义变量、40px 标题栏、208px 导航、64px 页头和 24px 状态栏。

## 信息结构

- 页头：AI 工作台 / 分析想法 / 导入及目录菜单 / 新建记录。
- 48px 工作视图切换：收件箱、全部、方法流程、决策复盘、个人原则、回收站。
- 主工作区：快速记录 → 搜索和项目/类型过滤 → 批量整理工具 → 40px 行高数据表 → 分页。
- 选中记录后出现编辑区，主表收窄到 42–44%，只保留记录、类型和更新时间；退出详情恢复完整表列。
- AI 面板占用同一详情位置；显示所选来源、输入目标、流式输出、结果编辑与保存。
- 项目详情新增「知识记录」页签，使用同一数据源，无重复内容。

## 状态

包含空数据、筛选为空、加载、保存等待/进行/失败、选中、悬停、回收站只读、冲突另存、AI 配置缺失/生成/中止/失败/重试。菜单和表内标题支持键盘焦点，快速记录 Enter 保存，Ctrl/Cmd+K 搜索，Ctrl/Cmd+S 保存。

`personnel-plm-desktop-v2.pen` 仍保留原桌面改版的历史画板，其中工作台、AI 助手、活动报告不再代表当前导航。此次功能迭代以可运行界面、此交付说明及 `output/desktop-v2-review` 的浏览器验收截图为准。
