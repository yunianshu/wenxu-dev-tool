# 一键正式发布

- R1：选项目并保存正式服务器 SSH 地址/凭据后，可一键自动发布；无需填写构建命令、产物目录、远程安装目录。首次准备环境包含在一次发布操作中。
- R2：新项目不继承其他项目的版本、目录、数据库和发布脚本；显式复制只复用服务器连接信息，新项目目标仍独立。
- R3：自动识别多模块项目；已有 Compose 优先使用，缺部署文件时使用已配置 AI 生成完整容器部署方案。无法可靠生成时提供具体原因，禁止虚报就绪。
- R4：自动模式在远端容器构建，每次发布使用新快照，不修改源项目版本；程序安装缺失的基础运行环境、生成内部随机凭据并跨版本保留持久化数据。外部密钥不能编造。
- R5：发布前验证生成方案、构建文件、项目目录边界及远端目录归属；AI 产物不覆盖业务源代码、不使用特权容器或宿主系统挂载。
- R6：失败保留日志并自动回滚，取消能终止准备阶段。项目和目标隔离，已有手动发布模式继续可用。
- R7：修复版本前缀误匹配、固定排除构建产物、脚本子目录被重置、无效打包前改写源版本等问题，并加入回归验证。

验收：临时项目与模拟 SSH 验证自动发布编排；真实 Bash 验证准备/部署/回滚协议；SecWatch 仅作为只读多模块样例。实现期间不向真实生产主机发布、不改 SecWatch 业务文件。
