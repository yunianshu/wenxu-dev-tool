# 实现设计

- R1/R2：配置增加 auto 部署模式、正式目标标识与端口。新配置默认 auto；已有 docker/script 保留。正式服务器简表只展示连接字段，自动计算隔离目录。
- R3/R5：新增 auto-deploy 模块，递归有限深度收集经过脱敏的构建/运行配置，复用 AI complete、scanLocal。生成结果包含 Compose、Dockerfile 与运行配置声明；严格校验路径、服务特权、挂载、环境变量，作为 ZIP 覆盖条目写入归档，不写业务项目。
- R4：服务器准备脚本按官方软件仓库安装 Docker/Compose 及解压工具，要求 root 或免密 sudo，不修改防火墙。用户目录内保存项目归属与共享配置。固定 Compose 项目名隔离网络/数据卷，每次发布独立 release 目录及镜像标签。
- R4/R6：复用 deploy-service 的单任务锁、事件流、历史及 deploy.sh；自动准备持有同一个活动任务，AI 请求可取消。服务端检查全部服务与 healthcheck，不能仅有数据库启动就判成功。
- R7：产物匹配使用版本边界、支持有限子目录；忽略规则支持反向规则；本地自动打包在隔离副本执行版本同步及发布说明生成，失败不污染源工作区。
- 验证：针对新配置、AI JSON 验证、自动发布编排、Bash 参数/回滚及旧手动模式运行最小充分测试，再构建渲染层。Git 仅提交本任务文件并推送 main。
