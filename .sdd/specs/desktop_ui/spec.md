# 桌面 UI v2 实现

## 目标与验收

按 `design/personnel-plm-desktop-v2.pen` 与 `design/desktop-v2-handoff.md` 实现十个真实业务页面，提供浅色、黑色主题及持久化选择。窗口使用 40px 标题栏、208px 侧栏、64px 页面工具栏和 24px 状态栏，表格 40px 行高，控件 32px。在 1280×720、1440×900、1920×1080、2560×1440 中保留可访问的工具栏和独立内容滚动。

所有页面继续使用现有 IPC、业务状态与操作逻辑。项目上下文仅应用于原本关联项目的功能；活动报告维持全项目范围；填报绑定与提交校验、部署九阶段与日志、终端会话以及 Harness 内嵌页面保持真实可用。不得使用设计图示例数据替代运行时数据。

## 实现方案

- 保留页头 Teleport 目标；拆出独立可拖动窗口标题栏。
- 使用现有 Element Plus 组件，通过统一语义变量适配两主题、选中/悬停/焦点/禁用等状态。
- 主题通过既有 `ui-prefs.json` 持久化；启动快照只用于避免闪白，后台偏好为权威来源，延迟读取不得覆盖用户新选择。
- 页面分别重构 master/detail、对话/Inspector、填报明细/摘要、部署阶段/日志等真实工作区域。
- 终端字体入口遵循最新代码约定，仅在设置页提供，不恢复设计初稿中的旧工具栏按钮。
- 不接管 Harness 外部应用内部主题；仅统一外层窗口，保留其自有主题控制。

## 验证

渲染层构建；现有业务与 UI 状态自测；主题实际临时文件读写、旧配置迁移、迟到读取及失败处理；隔离浏览器夹具逐页切换、两主题与四尺寸截图/溢出检查。最终核查差异，仅提交本任务文件并推送当前分支。
