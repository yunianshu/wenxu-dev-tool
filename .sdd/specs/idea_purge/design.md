# 永久删除记录设计

规格 1—3：编辑器更多菜单只在 deleted 状态发出 delete 事件，工作台确认框冻结 ID、revision、contentHash。增加 knowledgeDelete API/knowledge:delete IPC；后端复用 ID/路径验证和记录锁，读取后校验回收站状态、版本、摘要并 unlink 指定 Markdown 文件。

规格 4—5：状态仓库永久删除分支等待既有保存完成、阻止并发编辑，不强制写回已入回收站的草稿；成功后清理记录、计时器、草稿与备份，并记录本会话已删除 ID，屏蔽迟到列表和编辑事件。已有 save 必须读取原 ID 文件，不允许重建不存在的记录；来源关联保持原 ID。

验证：文件自测覆盖删除限制、真实移除、失败保护与旧保存拒绝；状态自测覆盖读取乱序、备份清理和失败恢复；真实 Electron/Tauri RPC 自测与桌面隔离页面的确认、取消、成功删除验证；构建。
