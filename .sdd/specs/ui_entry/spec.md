# 操作入口收敛规格

1. 想法创建只保留地球输入，记录列表只通过「全部记录」页签进入；移除顶部新建、列表空态新建和地球底部跳转。
2. 相同页面上同一对象的相同操作必须只保留一个可见入口；项目和扩展重复右键、双击、底部操作栏应移除。
3. 全局功能以既有侧栏、页签或页头入口为准；移除重复能力卡片、配置内服务器管理、设置内更新日志和重复 Harness 更新按钮。
4. 不同对象或结果的操作应保留：指定项目创建终端不同于打开终端页；平台目录不同于单个扩展目录；外部 PowerShell 不同于内置终端。
5. 空态和未配置提示必须说明唯一入口位置；键盘导航与保存快捷键、错误重试、回收站恢复保留，业务数据不变。

验收：地球输入仍能创建编辑记录；列表、项目编辑/删除和扩展操作各自可达；服务器管理、更新日志与 Harness 更新仍保留一个入口；不存在本规格指定的重复按钮，现有隔离页面测试通过。
