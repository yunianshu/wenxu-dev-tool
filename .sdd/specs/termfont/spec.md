# 终端工作台字体设置

沿用现有界面偏好与 xterm 渲染链路，提供字体名称、字号、预览及恢复默认。需求明确且可回退，规格与设计合并记录，不建立额外审批步骤。

## 验收

- 工作台可直接打开字体设置，设置页「界面」提供同一入口内容；两处状态一致。
- 可选择常见等宽字体或输入本机字体名称；默认沿用原回退栈，未安装的字体自动回退。
- 字号沿用 11～22px、默认 13px；预览即时更新，恢复默认同时重置字体与字号。
- 当前全部窗格立即生效并重新适配行列数，不关闭或重建终端会话；新窗格和切页返回沿用设置。
- 重启后恢复已保存字体；旧 ui-prefs.json 兼容，修改字体不清除侧栏/字号偏好，迟到的初始化读取不覆盖用户的新选择。

## 实现与验证

新增 terminalFontFamily 字段保存单个字体名称，空字符串表示默认。主进程和渲染层校验边界一致；通过现有完整偏好保存接口落盘。共享设置组件服务两个入口，TerminalPane 仅更新 xterm 外观选项并调用现有适配流程。

使用临时配置持久化测试、真实 Electron 隔离用户目录验证及前端构建；不读取或修改用户的真实设置，不安装字体，不发布安装包。

## 验证结果

- `terminal-font-selftest.cjs`：5 组通过，包含旧配置迁移、字体名称边界、偏好互不覆盖、迟到读取与保存失败重试。
- `terminal-font-e2e.cjs`：21 项通过，使用两次真实 Electron 启动验证字体选择、预览、所有窗格更新、新窗格继承、会话不重启、设置页同步、持久化恢复与默认值。另完成隔离界面截图检查。
- `terminal-workbench-selftest.cjs`：45 项通过；`ui-state-selftest.cjs`：5 组通过。
- `npm run build:renderer` 与差异检查通过。终端自测清理期间出现 node-pty 的 AttachConsole 辅助进程提示，45 项断言及退出状态均通过；新增字体 E2E 未出现渲染错误。
