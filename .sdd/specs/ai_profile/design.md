# AI 多配置设计

对应规格 1—4：在 ai 下增加 profiles、activeProfileId。顶层地址、模型、温度继续表示当前配置，兼容现有 AI 调用。读取时将旧配置转换为稳定 ID 的默认配置；保存时按 ID 合并凭据，再从当前配置生成顶层投影。

对应规格 3、5：沿用 safeStorage/keyring，配置密钥分别使用独立引用，留空按配置 ID 保留原密文。所有配置读取时脱敏。测试与模型列表请求携带配置 ID，禁止回落到其他配置凭据。

对应规格 1—3：设置页增加配置选择、新增与名称编辑。切换前保存当前编辑，失败保持当前选择；新增创建独立配置。切换时清空模型列表与连接测试结果，异步返回须检查配置身份。

验证：隔离存储覆盖旧配置迁移、两配置凭据隔离、切换与编辑持久化、清除和不可解密密文保留；执行渲染构建及已有 Tauri 凭据测试。
