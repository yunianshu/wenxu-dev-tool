# 共享部署服务器设计

- R1/R3：沿用 deploy-projects.json，在同一文档增加 servers 集合和 schemaVersion，targets 仅保存 serverId。以临时文件替换原文件一次落盘，避免跨文件迁移中途丢引用。完整连接与凭据相同才合并；解密失败时只比较原加密数据，不把失败当空口令。
- R2/R5：list() 为旧调用方解析 serverId 并返回脱敏 server 视图；getCredentials() 从全局服务器取密钥。项目保存忽略已引用服务器的表单连接副本，兼容尚未带 serverId 的旧接口输入；切换服务器清除该目标的远端运行状态，自动目录仍依赖稳定项目/目标 ID。
- R1/R4：提供 servers:list/save/remove IPC；管理弹窗支持名称、地址、SSH 认证与引用展示，引用中禁止删除。项目页与高级设置只选择服务器，项目端口/路径不进入服务器表单。
- 验证：临时数据模拟迁移、凭据保留、共享更新、防覆盖和删除拦截；真实 Electron 验证一次建服务器后两个项目复用与独立目录；相关自测与渲染构建。
