# 共享部署服务器

服务器归部署功能统一管理，项目选择服务器并保留独立安装目录。

- R1：新增、编辑服务器一次，所有引用项目共享地址与 SSH 凭据；[两个项目选择同一服务器] → [只保存一份连接，修改后两个项目均读取新值]。
- R2：项目必须能选择服务器；[切换项目或服务器] → [安装目录、端口、发布目标及历史不串用]。自动模式仍按项目和目标生成独立目录，不要求手填路径。
- R3：旧配置自动迁移；[多个目标连接和凭据完全一致] → [合并为一台服务器，原目标 ID、目录与加密凭据保留]。凭据冲突不静默丢弃。
- R4：被项目引用的服务器禁止删除；[尝试删除] → [列出引用项目，配置不变]。未引用服务器删除仅清本地配置，不操作远端。
- R5：项目保存禁止覆盖共享服务器连接；[旧项目表单保存] → [全局已更新凭据不被覆盖]。服务器凭据仍加密存储，渲染层只得到配置状态。

范围：服务器管理、项目选择、兼容迁移与验证；不连接真实生产、不发布安装包、不迁移远端数据。
