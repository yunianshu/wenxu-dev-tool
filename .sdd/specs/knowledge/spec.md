# AI 工作台与知识沉淀

## 用户目标

移除独立「AI 助手」「活动报告」，默认工作台改为「AI 工作台」，用于项目知识沉淀、随手记录、整理与想法分析。

## 范围与验收

- 应用导航仅保留 AI 工作台、项目、Harness、终端、一键填报、部署、扩展、设置；一键填报继续复用 Git 采集。
- 无项目、无 AI 配置也能记录知识。类型包含想法、问题、决策、经验、方法、SOP、原则、AI 技巧；状态与类型分离。
- 收件箱、全部记录、方法流程、决策复盘、原则、回收站是同一份数据的视图，支持搜索、类型/项目筛选、排序、多选和分页。
- 记录独立保存为本地 Markdown，支持自动保存、手动保存、修订冲突提示、导入导出、软删除和恢复。
- 项目详情可查看关联记录；删除项目不删除知识，保留历史名称。
- AI 仅接收明确选中的来源和当前输入，流式生成可停止；输出由用户保存为可编辑草稿，保留来源链接，不自动覆盖原文。
- 浅/黑主题与 1280×720、1440×900、1920×1080、2560×1440 可用。

## 边界

不迁移或删除旧报告历史，不执行外部 Git 同步，不增加 RAG、知识图谱、后台定时 AI 或团队权限。已有本地目录可自行用 Git 管理。
