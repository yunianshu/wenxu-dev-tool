# 桌面架构迁移规格

## 目标

将 Personnel PLM 的桌面运行环境迁移为 Tauri + Vue + 随包 Node 后台，保留现有 Windows、macOS、Linux 功能，并以实际安装包和运行指标评价体积与性能。

## 用户可见验收条件

1. **现有工作台**：用户安装新版本并启动 → 项目、AI 助手、Git 报告、终端、填报、部署、扩展管理和设置可以继续使用，原有数据可读取。
2. **离线启动**：用户在没有全局 Node 的机器上安装完整版 → 应用和内置 Harness 可启动；可配置的自动启动、停止、重启及退出清理仍生效。
3. **Harness 页面**：用户在应用中打开 Harness → 完成一次性登录并显示完整界面；在浏览器打开、刷新、全屏与退出全屏可用。
4. **终端与进程**：用户打开多个终端并切换页面 → 会话和有界回放保留，窗口退出后后台进程被清理。
5. **升级与数据**：用户从现有 Electron 版本迁移 → 配置、项目和历史记录可读取；已保存凭据可继续使用，或有明确且可恢复的迁移路径。Harness 升级失败时旧版本仍可启动。
6. **分发**：各支持平台可生成可安装产物 → 记录文件大小和启动/内存指标；Windows 安装器在无 WebView2 时给出明确安装路径。

## 边界

不改动 AI、Git、部署和填报的业务规则；不执行生产部署；不删除现有用户数据。
